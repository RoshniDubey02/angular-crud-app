# Angular CRUD Application

A single-page Angular CRUD application built using Angular Material and REST API.

## ✨ Features
- Angular Material Table
- Create, Read, Update, Delete (CRUD) operations
- Single-page UI (no routing complexity)
- REST API integration using JSONPlaceholder
- Optimistic UI updates for Add/Edit/Delete
- Error & success handling using Angular Material Snackbar
- Responsive and clean UI

## 🛠 Tech Stack
- Angular 21
- TypeScript
- Angular Material
- REST API (JSONPlaceholder)

## 🔗 API Used
- https://jsonplaceholder.typicode.com/users

> Note: This is a mock API. Data does not persist after page refresh.
